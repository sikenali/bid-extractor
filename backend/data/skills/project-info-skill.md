  - field: 项目编号
    type: regex
    pattern: '(?:项目|采购|招标|工程)(?:编号|编号ID|No.)[：:]?\s*([A-Za-z0-9][A-Za-z0-9\-_/．.]{3,40})'
  - field: 投标截止时间
    type: regex
    pattern: '(?:投标|递交|应标)(?:文件)?(?:递交)?(?:截止)?时间[：:]?\s*(.{0,30}?(?:年|月|日|时|分).{0,20})'
  - field: 采购人
    type: keyword
  - field: 采购代理
    type: keyword
  - field: 预算金额
    type: regex
    pattern: '(?:(?:采购|项目|招标)\s*)?(?:预算(?:金额)?|最高限价|招标控制价|采购预算)[：:]?\s*(?:人民币\s*)?[¥￥]?\s*(\d+(?:,\d{3})*(?:\.\d{1,2})?)\s*(?:万元|万|元)?'

# 项目信息抽取技能

本技能用于从招标文件正文中抽取项目信息类字段：项目名称、项目编号、投标截止时间、
采购人、采购代理机构与预算金额。正则规则优先精确匹配，关键字规则用于兜底召回。
